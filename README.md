# mohipa — مرشح الإصدار 1.0.0

مشروع SwiftUI لـ iOS 15 فأحدث. يشمل البحث في فهرس App Store العام بالاسم ومعرّف الحزمة ورابط المتجر، واختيار واجهة البلد، وعرض النتائج، واستيراد ومشاركة ملف IPA موجود من تطبيق الملفات. تحفظ المكتبة ملفات IPA في تطبيق «الملفات» تحت تصفح ← على الـ iPhone ← mohipa. يظل الملف محفوظًا بعد إغلاق التطبيق وفتحه مرة أخرى. وظيفة التنزيل تحفظ الملف فقط. يمكنك حذف الملفات ومشاركتها وتنزيلها من روابط HTTPS مباشرة. يتحقق الاستيراد والتنزيل من وجود بيانات الحزمة داخل Payload ويعرض الاسم ومعرّف الحزمة والإصدار عند فتح المعاينة. لا تتحقق المعاينة من توقيع الحزمة. البلد الافتراضي السعودية.

لم يضف هذا الإصدار تسجيل Apple ID أو تنزيل حزم App Store أو نسخ الإصدارات القديمة. البحث العام يعرض بيانات الفهرس، وفتح نتيجة يفتح صفحة المتجر.

على macOS مع Xcode وXcodeGen

```sh
xcodegen generate
xcodebuild -project mohipa.xcodeproj -scheme mohipa -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO build
```

لم يُشغّل بناء Xcode في هذه البيئة.

مسار GitHub Actions يبني التطبيق للمحاكي عند الرفع. لا يحتاج شهادة توقيع. لم يُشغّل بعد.

يمكن إلغاء تنزيل الرابط أثناء العمل. إذا انقطع الاتصال أو رفض المصدر الرابط، تظهر رسالة توضّح السبب ويمكن إعادة المحاولة من نفس الحقل. اسحب قائمة المكتبة للأسفل لتحديثها بعد تغيير الملفات من تطبيق «الملفات».

مسار GitHub Actions يبني المشروع ويشغّل اختبارات فحص IPA على محاكي iPhone. تغطي الاختبارات حزمة ببيانات صحيحة، وأرشيفًا عامًا، وحزمة بلا معرّف تطبيق.

بعد نجاح اختبارات المحاكي، يجهز GitHub Actions ملف mohipa-1.0.0-unsigned.ipa لجهاز iPhone. يتحقق من إعدادات ظهور الملفات في تطبيق «الملفات» قبل رفع الـ IPA كأثر بناء. الملف يحتاج توقيعًا لتشغيل mohipa على الجهاز.

يمكن إدخال بصمة SHA-256 المنشورة من مصدر الملف لمقارنة البصمة قبل حفظ IPA في تطبيق «الملفات».

كود mohipa الأصلي مرخّص بترخيص MIT. يعتمد فحص الأرشيفات على ZIPFoundation بترخيص MIT.
